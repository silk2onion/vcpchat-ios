# VChat for iOS

连接自有 VCP 服务的原生聊天客户端。采用 SwiftUI + Swift 6，支持 iOS 17 及更新版本。

> 当前为原生重构预览版：已接通聊天、实时日志和本机记录。完整同步、服务端文件操作与分布式节点仍在迁移中。

## 开始使用

打开 **我 → 设置 → 服务器与模型**，填写（聊天页也可快捷打开连接设置）：

| 项目 | 填写内容 |
| --- | --- |
| 服务器 | 手机可访问的 VCP 地址，建议使用 HTTPS |
| 聊天 API Key | VCP 聊天服务密钥 |
| 模型 ID | 直接填写，或点“鉴权并读取模型”后搜索选择 |
| VCPLog Key | 实时日志的独立密钥；与聊天密钥分开填写 |

保存后即可发送消息。需要实时日志时，在连接设置里点 **连接 WebSocket**，再打开聊天页的通知按钮，或进入 **我 → 通知与监视**。日志服务器可独立填写，留空使用聊天服务器。

已有桌面 VCPChat 连接可以通过 **导入桌面 VCPChat 连接…** 选择原版 `AppData/settings.json`。
只读取连接信息，不改原文件或旧会话；密钥保存在系统钥匙串。已保存的连接需在连接设置里主动点“解锁已有连接”后读取；未解锁也可查看本机记录，启动时不访问钥匙串。

模型列表支持搜索、最近使用和本机缓存。每次只展示一小批，点“再显示 40 个”继续浏览，数百个 ID 不会一次性铺满页面。

“OpenAI 兼容”使用 `/v1/chat/completions`；“VCP 工具模式”使用 `/v1/chatvcp/completions`，都通过 SSE 流式接收。WebSocket 分别接收 VCPLog 与 VCPInfo 推送。

Temperature 默认不发送，只有打开“发送 Temperature”才会启用。Agent 可设置独立数值，否则继承全局数值。

## Agent 通讯录

在“通讯录”点 ＋ 创建 Agent，设置名字、简介、系统提示词和模型。模型留空时使用全局模型。
点 Agent 进入它的独立对话；右侧菜单可编辑资料或将其设为主 Agent。主 Agent 固定在“会话”顶部。
删除 Agent 不会删除历史消息。点 Agent 头像可从照片或文件选择图片，调整裁剪、缩放与位置；GIF 头像保留原始动画，按头像区域居中显示。

在“我 → 个人资料”设置你的名字与头像；资料保存在本机。

## 群聊

在“通讯录 → 创建群聊”选择成员、设置群提示词，并选择发言方式：@点名否则轮流、轮流一位、随机、仅点名、每位依次回复。
成员会保留各自身份和系统提示词，按顺序读取前面成员的回复。可为群聊指定统一模型；留空时使用各成员模型。
群聊支持独立话题、头像和发言顺序调整，停止生成会同时停止本轮后续成员。

## 聊天与本机记录

- 回复使用原生文字流式显示，可停止生成，已收到的内容会保留。
- 输入框使用系统原生文字编辑，支持多行输入，默认回车换行、箭头发送。在“我 → 设置”可改为回车发送，此时点输入框旁的“换行”按钮插入新行。
- 工具请求、执行结果、思考链、日记与工具摘要显示为原生卡片；流式未完成的卡片会保持展开。代码块中的协议示例不会被误识别。
- 聊天记录保存在本机，重启后可以继续查看。
- 点放大镜搜索本机消息，至少输入 3 个字符，支持中英文。
- 中断或失败的消息不会自动重复发送；最后一条助手回复可点“继续写”接着写，或在消息菜单选择重新生成。
- 消息支持复制、分享和编辑；编辑前保留本机旧版本。移除的消息可在对话菜单的“已删除消息”中恢复。对话菜单也可导出 Markdown。

每位 Agent 有独立对话，可从聊天顶部的历史按钮新建、切换、重命名和删除话题。每个话题分别保留草稿；切到其他话题时，正在生成的回复会继续接收。普通文字直接由原生 Text 显示；Markdown 标题、引用、列表和表格使用原生视图，代码支持语法高亮和复制，行内与独立公式使用原生数学排版。富内容在独立 Actor 中解析，可视区外停止解析。只有以 `<div id="vcp-root">` 开头的完整消息会进入独立视觉气泡；其余 HTML 按文字显示。视觉气泡可运行动画与交互，离开可视区或页面时释放运行环境，重新进入后重建；不会作为整个 App 的主界面。后台续流和系统推送尚未开放。

在 **我 → 设置 → 消息渲染** 可切换高级渲染、代码、公式、HTML、气泡动画与媒体；已有消息会立即按新设置重绘。

## 聊天附件

输入框的 ＋ 可选择照片、图片或文本文件，每条消息最多 4 个；图片上限 1.5 MB、文本上限 200 KB，不接受 SVG。附件与草稿按话题保存，也可只发送附件。点消息中的附件预览并导出原文件。只有最近一条用户消息的附件会进入本次模型上下文，避免重复传输历史大文件。

## 本机文件库

在 **我 → 文件** 导入原文件（单个不超过 20 MB），按文件名搜索、预览或导出；同一内容只保存一份。也可收集现有聊天附件副本，或把文件放回当前会话草稿，发送时仍遵守聊天附件大小限制。移除文件后可切换“查看已移除文件”恢复。导入同步历史缺失的原文件时，按协议内容哈希重新关联，不修改本机原有历史。

## 语音朗读

在 **我 → 设置 → 语音朗读** 配置原版兼容的 SoVITS v2ProPlus 或 MiMo TTS，填写独立服务地址与密钥，读取音色并试听。MiMo 支持默认音色及自然语言导演；Agent 可独立设置音色、语速和导演提示词，留空或选择继承时使用全局设置。

点助手消息下方的扬声器朗读正文，工具协议、代码和 HTML 标签不会念出来。长正文按最多 800 字分段合成，底部播放器支持暂停、继续、停止和进度显示；切换页面仍可控制播放。音频在原生 Actor 内处理与播放，不使用系统合成语音代替 VChat 的语音服务。

## 通知、工具审批与 RAG 监视

在 **通知与监视** 中切换通知、VCPLog 和 RAG 监视器。工具审批显示 Agent、命令、目标、完整参数与变更预览，可附说明后允许一次或拒绝；发送完成后显示“等待确认”，收到服务器回执后才显示最终结果。过期或已处理项目不会重复发送。

RAG 结果按原生卡片展示来源、分数、正文、检索方式与核心标签，也支持元思考链、Agent 会话、记忆与梦境事件。两个通道独立鉴权与自动重连，日志保存在本机并去除连接密钥；清理日志会保留尚未完成的审批。

## 笔记与服务器日记

在 **我 → 笔记** 创建、搜索和编辑本机笔记；编辑保留旧版本，删除后可以恢复。本机笔记不会自动上传。

进入“服务器日记”，填写日记管理员用户名与密码，刷新文件夹后可搜索、打开、新建和保存日记；沿用原版 `/admin_api/dailynotes` 接口与 UTF-8 Basic 鉴权。覆盖已有日记之前，会把原文存为一条本机备份笔记。服务密钥与聊天密钥一样，只有主动解锁才读取系统钥匙串。

## 正则规则

在 **我 → 设置 → 正则规则** 管理全局规则；编辑 Agent 时可设置专属规则，全局规则先执行。支持 VChat 与 SillyTavern JSON 导入导出、顺序调整、启用开关和替换预览。

可分别作用于消息显示、发送上下文、用户或助手消息，并限定轮深；一组相邻的用户/助手消息计为同一轮。规则只处理显示或发送副本，不修改已保存的原文。复制与分享使用显示后的内容。

## 外观与壁纸

在 **我 → 设置 → 外观与壁纸** 切换墨色、纸色、极光主题，选择林间夜游、雨后绿叶、纯色或自己的照片。背景遮罩范围为 15–90%，模糊范围为 0–16 px；推荐值为 58% 与 0 px。自定义图片不超过 8 MB，静态图片保留比例并缩至最长 2560 像素；GIF 由原生图片视图播放，离页、后台或开启系统“减少动态效果”时暂停。

## 安装

目前通过源码运行：使用完整版 **Xcode 16 或更新版本** 打开 `VChat.xcodeproj`，选择 **VChat** 和 iPhone 模拟器后运行。
安装到自己的 iPhone 时，在签名设置中选择开发团队，并启用手机的开发者模式。

同一套原生代码也支持 macOS 14+。使用 Swift 6 构建根目录的 Swift Package 可运行 Mac 客户端。

## 数据与隐私

连接密钥保存在系统钥匙串。聊天记录使用独立的本机数据库，不会覆盖旧客户端的数据；当前版本不会自动导入或同步旧会话。
发送消息时，会把当前会话内容发送给你配置的 VCP 服务。请使用可信服务器。
