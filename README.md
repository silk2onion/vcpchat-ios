## 快速开始

### 1. 安装到 iPhone

下载[最新稳定版](https://github.com/silk2onion/vcpchat-ios/releases/latest)；预发布版在[全部版本](https://github.com/silk2onion/vcpchat-ios/releases)中标为 **Pre-release**。使用 AltStore 等侧载工具签名安装 IPA，需要 **iOS 17 或更新版本**。

[0.3.6 beta 4 更新说明](docs/releases/0.3.6-beta.4.md)（build 22）

更新时沿用原签名账号与应用标识，直接覆盖安装，保留已有数据。

### 2. 连接 VCP

准备一个手机可访问的 VCP 服务，打开 **我 → 设置 → 服务器与模型**：

| 项目 | 填写内容 |
| --- | --- |
| 服务器 | 你的 VCP 服务地址 |
| 聊天 API Key | 对应服务的聊天密钥 |
| 模型 | 输入模型 ID，或点击“鉴权并读取模型”后选择 |
| 接口 | 连接 VCP 时选择“VCP 工具模式”；其他兼容服务选择“OpenAI 兼容” |

已有桌面配置？点击 **导入桌面 VCPChat 连接…**，选择桌面的 `AppData/settings.json`，也可导入手机配对文件。

### 3. 开始对话

在 **通讯录** 点 ＋ 创建 Agent，设置名字、提示词和模型，点开即可聊天。将常用角色设为主 Agent，就能从 **会话** 顶部快速找到它。

想让多个角色一起参与，在通讯录中创建群聊并选择成员。聊天顶部可新建或切换话题；长按消息可复制、编辑和分享，对话菜单可导出 Markdown。

会话首页按话题创建和最后一次用户或助手发言中较晚的时间排列，同步和重命名不会把旧话题顶上去。在「历史话题」点铃铛可切换「最近对话 / 创建时间」。点「调整顺序」再拖动可手排，再点铃铛回到上次的自动排序。要让某条话题留在原位，在它的「…」菜单选「固定排序位置」。

### 锁屏等回复（iPhone）

**可选：VCP 回复续传。** 安装随附的 [VChatReplySync 服务插件](Companion/VChatReplySync/README.md)，在「后台回复与提醒」里打开「使用 VCP 回复续传插件」。服务端负责这一轮生成；断网、切后台或重开 App 后，手机按原任务补齐，而不会让模型或工具从头执行。前台仍流式显示，离开时用简洁实时活动；App 完全挂起期间不保证岛实时刷新。未装插件时使用以下直连模式。

在 **我 → 设置 → 后台回复与提醒** 打开 **后台收回复**，再发送消息，就可以切到其他 App 或锁屏。前台使用流式回复；回到聊天时补上当前已收到的正文、思考和工具回执。仅一次性返回完整结果的服务会在结果到齐后显示。开启之前已经发出的请求仍沿用原模式。

- 点 **允许回复完成通知**，后台收到回复时会用苹果原生通知提醒，点通知回到原话题。锁屏不显示正文；不授权也会保存回复。
- 开启 **在锁屏与灵动岛显示进度** 后，离开 App 时仍在进行的请求会显示实时活动，按实际收到的正文和思考字节更新进度。使用紧凑的实时活动。系统挂起 App 时岛可能暂停更新；直连模式回到前台后，连接仍在就补齐，连接已断则保留已收到的部分；灵动岛需机型支持。系统设置可关闭实时活动，专注模式也可能让通知静音。
- 系统可能延后传输或提醒。从多任务界面强制退出会取消后台传输。不会自动重发；未完成的消息可以在原话题重新生成。群聊中，尚未发出的后续成员请求仍需要 App 获得执行时间；依赖手机前台文件节点的工具在锁屏时仍会暂停。

## 连接你的工作空间

### 桌面同步

先在桌面 VCPChat 启用支持 **Wire 1.6** 的 **VCPMobileSync**，再进入 **我 → 桌面同步**，填写插件提供的 HTTP 地址、WebSocket 地址和同步 Token。默认端口分别为 **5974** 与 **5975**。

首次连接选择 **只拉取桌面内容**，导入 Agent、群组、会话与头像，保留手机原有记录。需要将该同步来源内的修改和删除写回桌面时，选择 **双向同步**；手机独立会话不上传，群聊历史窗口仍由各端单独设置。同步后可从本机恢复点找回此前内容。列表显示日期及同步前后的话题数；确认恢复时才读取所选备份。升级后会为旧恢复点一次性建立索引，备份内容不变。正在生成的回复需先结束；待确认的用户消息可以作为记录同步，手机仍保留待确认状态，不会自动重发或标记送达。若桌面删除或修改了同一条待确认消息，会停止本机替换并提示处理冲突。

### 文件与笔记

进入 **我 → 文件**，导入、预览和分享文件，或将文件加入聊天。

- **连接文件夹**：选择工作目录，直接浏览和编辑文件；为 Agent 单独授予只读或读写权限。
- **服务器文件**：连接 VCP FileOperator，管理远端目录与文件；下载原件时配置 File Key 和分发目录。
- **笔记与日记**：在 **我 → 笔记** 记录想法；连接服务器日记时，使用日记管理员账号。

需要 Agent 操作手机文件时，可在连接文件夹中启用 **移动版 FileOperator**，让已授权的目录成为 VCP 分布式节点。手机节点在 App 前台运行。

移动工具节点的 TopicMemo 可以用 `OutlineTopic` 查楼层大纲，用 `SearchTopic` 在指定话题内找关键词，再用 `GetTopicContent(startSeq: N, endSeq: M)` 读取这几楼原文。楼层从 1 开始，沿用本机 Agent 读取授权。

### 通知与检索

在连接设置中填写 **VCPLog Key** 并连接 WebSocket。点击聊天页的通知按钮，或进入 **我 → 通知中心**，即可查看实时日志、RAG 来源与检索正文，以及需要确认的工具操作。

## 按你的习惯使用

- **外观**：在 **设置 → 外观** 选择主题与壁纸，也可使用自己的照片或 GIF。
- **语音**：在 **设置 → 语音与朗读** 连接 SoVITS v2ProPlus 或 MiMo TTS，为不同 Agent 设置音色，点击消息扬声器开始朗读。
- **正则**：在 **设置 → 全局正则** 管理显示与上下文规则，支持 VChat 和 SillyTavern 配置导入；Agent 也可使用专属规则。
- **输入与渲染**：在设置中选择回车发送或换行，在高级渲染中调整代码、公式、图表与 HTML 气泡的显示。Markdown 加粗支持紧邻中文的引号与括号，并随主题显示强调色；代码示例中的星号保持原样。
- **高级回复**：在 **我 → 设置 → 高级回复** 启用气泡、HTML 多媒体或工具提示词预置，也可新建规则。选择系统提示词尾部、本轮用户消息尾部或按深度插入上下文；在同一位置按列表排序。可为 Agent 或群组覆盖全局启停，返回后保存。旧气泡输出开关会沿用；其他预置默认关闭。工具需要实际服务或节点支持，规则只进入新请求，不写回历史，也不随桌面同步传输。

从聊天右上角的「… → 搜索本机消息」点选结果，会打开它所属的话题，定位并短暂高亮原消息。此时不会被新回复拉回底部，点「回到最新」即可恢复跟随。

JEV 自然语言工具请求优先显示指定的工具名，其次显示花括号里的能力名。没有名字时显示「JEV 请求」；展开可读原文。

在 iPhone 聊天时，点击发送按钮或使用已启用的回车发送后，键盘会自动收起。只想多看几行历史时，可点键盘上方的 **收起键盘**，草稿会保留。

展开「本轮工具调用摘要」可查看本批执行状态和返回正文，同一份结果只显示一次。没有摘要的结果仍可单独展开；工具输入和思考过程各自独立。如果连接 VCP 时只看到状态，可以在 **我 → 设置 → 服务器与模型 → 接口** 选择 **VCP 工具模式**。选择后自动保存，对新请求生效。过去未收到的结果不会补写。

后端启用 `VCP_FC_FORWARD_TO_CLIENT=true` 时，原生 DailyNote 的新建和修改会直接显示为日记卡；其他函数调用可以点开「函数调用 · 工具名」查看参数。工具由后端执行。重开单聊或群聊后，下一位发言的 Agent 仍能收到原始调用 ID 和完整的批量回执。

工具返回批次会显示为回执，保留工具结果和本轮摘要，不显示时间戳协议标记或批次自带的角色分隔。展开原来的折叠卡即可查看表格、列表、链接、代码块和 Markdown 图片；回执里的 HTML 按原文显示。

在 iPhone 上长按助手回复的文字可以拖动选区，再点「复制」或「单独追问」。追问只引用选中的原句，发送后作为独立话题保存；点「完成」回到原对话。长按气泡留白（或点「…」）打开整条消息的菜单。单聊和群聊都可以点「从这里另开话题」，保留截至这条消息的历史，原话题不变。

### 聊天图片与表情包

在本机笔记、服务器日记或记忆编辑器打开「渲染预览」，点图片或画室图片链接进入联览。左右滑动可看同一篇的其他图片。

在 iPhone 上点开 Markdown 图片，再点「保存到照片」，也可长按图片直接保存。HTML 卡片里长按要保存的图片，预览后点「保存到照片」。保存的是原图文件；首次保存只需允许添加照片，不需要读取相册。

普通网络图片按聊天气泡可用宽度等比预览，特别长的图限制预览高度，可点开看原图。表情按标签指定的小尺寸显示。原生消息里的远程图片和 HTML 气泡里的普通 HTTPS 图片共用本地缓存。第一次成功加载后，关闭再打开 App 仍可命中；缓存受系统清理、服务器缓存策略和容量限制（128 MiB、最多 2048 项，默认最长 7 天）。VCP 图片服务对固定表情通常返回 `public, max-age=0`；对不含查询参数的命名表情，App 将原图作为聊天的离线副本保留最多 7 天。普通网址仍按缓存时效处理；明确要求 `no-store`、`no-cache` 的图片、登录页和错误响应不会保留。HTML 气泡里的 SVG 和需要跳转的 HTTPS 图片，仍由 WebKit 按原链接显示，不写入光栅图缓存。视频、CSS 背景图、动态脚本插入图片和带 `srcset` 的响应式图片不在这套磁盘缓存内。

在「我 → 设置 → 高级渲染」点「从当前 VCP 更新目录」（使用已配置的管理员账号），或导入桌面 `emoticon_library.json`。有目录后，先按文件主名匹配，同名时优先原分类，再按相似度纠错。如果服务器部署在 `/vcp` 等子路径，更新目录和相对表情地址都会保留此前缀。目录只存分类和文件名，原消息、普通外站图片不改。相对表情地址需配置 File Key；同主机反代的 HTTPS 表情旧 6005 端口会按当前标准 HTTPS 入口解析。可在同一页清除聊天图片缓存。

流式代码围栏在打开时用字面文本更新，收口和终稿再进行规范解析。零缩进的桌面动画卡片在外层闭合后可以启动，其中的脚本可以通过 `container` 找到卡片。旧卡片根节点后紧跟的样式和初始化脚本仍随卡片加载。追加内容和终稿保留已有图像节点和动画状态；消息被替换时重新创建该气泡。代码块与行内代码里的图片标签仍按示例文字展示。

### 双曲场图

在 iPhone 的 **发现 → 双曲场图** 打开 VCP 服务上的 Tag 场或 Chunk 场。使用聊天服务器地址和聊天 API Key，服务端需启用 WarpedFieldAtlas 并有对应快照；不需要桌面端或桌面同步。单指拖动、双指缩放或点 ＋／−，点选节点或按名称搜索可查看详情。切换到查询可比较双曲距离与余弦排名；后端支持时可按对话消息查询，或切换到黎曼切片。更新快照后点右上角重新加载。单次响应默认最多 32 MiB，可在场图右上角调高或选择「不限」。

### 对话上下文

默认发送当前话题的完整历史及可用附件，不按固定消息条数截断。已同步的文本附件可使用提取正文；尚未下载的图片会明确标记为未附带内容，可先在文件页下载原件。

在 **Agent 资料 → 上下文与输出** 设置上下文预算和最大输出 Token，双向同步时与桌面对应配置一同更新。上下文预算传给 VCP 工具接口处理，摘要与折叠需在服务端配置；OpenAI 兼容模式仅发送最大输出参数。留空沿用服务设置，最大输出为 0 时不发送该参数。

群聊默认也发送完整历史。只有在群聊资料中主动开启 **只发送最近的群聊消息**，才使用指定消息条数的滑动窗口；它会省略早期上下文并改变历史前缀。上下文正则的轮深限制同样可能改变旧消息；仅调整外观时使用显示正则。

### 位置共享与常用地点（预览版）

进入 **我 → 设置 → 位置共享**，开启自动共享并选择 Agent。首次使用需允许系统定位；也可从聊天输入框的 **＋ → 附带当前位置** 只分享这一条，点位置提示旁的 × 可让本条消息不附带位置。

打开 **常用地点**，添加任意名称、别名、地址和备注，或到达地点后保存坐标。每个地点单独选择可共享的 Agent。没有预设城市、学校或公交线路；仅分享一次当前位置，也不会把未授权的常用地点一起交出去。旧版保存的家、学校与线路偏好会保留并迁移。

在 **Agent 资料 → 位置相关指引** 中定义用途。可以插入出行指引模板，再补充城市、服务器实际提供的工具和个人偏好；也可以用于附近搜索，或留空。这些指引不安装服务器插件，实时路线和班次需要后端已有相应服务。

位置只在前台按需获取，随本次请求附上测量时间、误差和精度，不自动写入本机聊天历史。后端启用 **MemoryThinkingTray**、深度设为 **1** 时，动态位置进入历史消息后的托盘；Agent 的位置指引保留在静态提示部分。获取失败时保留未知状态，不用常用地点推断当前位置。对已开启自动共享的 Agent，单次取消定位只把托盘标记为未共享，不发送坐标和常用地点，也不移除固定位置指引。位置和获准共享的地点会发送给你配置的 VCP 和模型服务。

聊天记录保存在本机，连接密钥保存在系统钥匙串。打开 App 时自动读取已保存的连接；已启用的日志通道和移动工具节点会在前台恢复连接。仅系统要求额外授权时才显示解锁入口。进入 **我 → 设置 → 本机数据**，可备份和恢复聊天记录。

## 从源码运行

使用 **Xcode 16 或更新版本** 打开 `VChat.xcodeproj`，选择 **VChat** 和 iPhone 模拟器运行。连接自己的 iPhone 时，在签名设置中选择开发团队。

也可通过 [GitHub Actions · Native iOS Build](https://github.com/silk2onion/vcpchat-ios/actions/workflows/native.yml) 构建模拟器 App 与未签名 IPA。

在 **macOS 14+**、**Swift 6** 环境下，可从项目目录运行 Mac 客户端：

```sh
swift run VChatMac
```
