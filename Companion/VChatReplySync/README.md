# VChatReplySync · 回复续传

给 iOS 的**单轮生成**提供交接，不是帐号、联系人或多设备聊天历史同步。手机创建任务一次，插件连接本机 VCP 原有的聊天 / 工具接口并保存返回字节；手机离线不取消生成。恢复时只读取任务。无需改 VCP 核心、申请 APNs 或配置第二个模型密钥。

## 安装及试用

1. 需要运行单个 VCPToolBox 服务进程（Node.js 20+），支持 service 插件的 `hasApiRoutes` / `registerApiRoutes`。将整个 `VChatReplySync` 目录复制到 **自己的 VCPToolBox/Plugin/**，确认文件不是多套一层。插件无需 npm install。
2. 按现有运维方式重启 VCP 一次以加载 direct 模块。插件沿用服务的 `Key` 和 HTTP 监听 `PORT`，只连接同进程所在主机的 127.0.0.1，不读取用户指定的上游地址；反代应使用 HTTPS 并转发 Authorization、X-VChat-Proof、X-VChat-Route 和 PUT / GET / DELETE。若网关启用了浏览器交互验证，请只为本插件所需的方法和路径配置 API 规则，保留认证及限流。若有路径白名单需允许 `/api/plugins/VChatReplySync/`。不要把仅给受限模型访问的网关凭据映射到一个拥有更广权限的 VCP Key；反代的模型/租户策略需同样覆盖插件入口。
3. 用原来的聊天密钥读取 `GET /api/plugins/VChatReplySync/capabilities` 应得到 version 1。使用带「后台回复与提醒」设置的 iPhone 客户端，在 **我 → 设置 → 后台回复与提醒** 打开 **后台收回复** 和 **使用 VCP 回复续传插件**；想看工具详细结果，在服务器设置选择 **VCP 工具模式**。对新请求生效。未安装时关闭插件选项可继续原直连；已提交的任务不会自动改为直连重发。
4. 发一条慢回复，看到首段后切后台；重新打开原话题应补齐正文、思考和工具回执。即使手机进程被终止，已被插件接受的这一轮仍可生成；系统强退可能取消本机提醒，下次启动再取。为恢复原任务，手机在钥匙串临时保存原服务器地址、聊天密钥和该任务专用凭据，回复落库后清理。仅在使用系统钥匙串持久化凭据的构建中支持跨进程恢复；会话级密钥模式不额外持久化。群聊中下一位尚未发起的请求仍需手机运行。
5. 插件模式使用 VChat 的简洁实时活动，不提交 iOS 的持续处理大卡。系统挂起 App 时，岛上进度可能停在上次值（没有 APNs 远程更新）。插件提供终稿下载给 iOS 后台传输，系统何时唤醒并发本地通知取决于设备；通知被拒绝不影响恢复。手动点停止会请求服务器终止，已发生的工具操作不能撤销。

## 保存与边界

单机目录 `PluginData/VChatReplySync/<随机 UUID>/` 存放原始输出和少量状态，包括工具回执、思考等私密数据；**不保存请求历史、API Key 或任务凭据明文**。目录仅服务帐户可读，放在持久卷上，不要托管为静态文件。终态默认留 24 小时，之后清理；每份最多 16 MiB、总体不超过 256 MiB，最多 8 个并发生成、256 份记录；超限拒绝新请求或保留前缀并报中断。一次最长 10 分钟。离线超过保留期无法补齐。服务重启后**已完成结果**仍能读取，进行中的任务标为中断并保留前缀，不自动重跑模型。仅支持单写进程，不支持多实例共享该目录。卸载前先停止接收新请求并读完需要的结果，再禁用插件并重启；删除数据目录会永久移除仍可恢复的结果。

## 线协议 v1

所有端点都需要 VCP 的 Bearer；除 capabilities 外，还需要设备为本任务生成的 256 位随机 X-VChat-Proof。ID 不是授权。任务不允许被列举。不使用管理员接口。

| 请求（前缀 /api/plugins/VChatReplySync） | 语义 |
| --- | --- |
| GET /capabilities | version、retentionSeconds |
| PUT /jobs/:UUIDv4 | 请求原有聊天 body（stream=true），X-VChat-Route 为 chatvcp 或 chat；持久占位后只启动一次。相同内容返回原任务，冲突 409。在保留期内幂等。 |
| GET /jobs/:id?offset=N | 最多等待 10 秒；返回 `id,offset,next,state,reason,data`。data 是 base64 原始响应；next 是下一字节位置。落后的读取最多每页 128 KiB，末页才报告终态。 |
| GET /jobs/:id/result | 等到终态返回相同格式的完整归档（offset=0）。等待时发送 JSON 前置空白，适于后台下载。 |
| DELETE /jobs/:id | 停止生成并保留前缀；已终态不覆盖。早于 PUT 到达的取消留占位，阻止迟到的生成。 |

状态：running / complete / stopped / interrupted。越界游标为 416；未知 ID、其他设备的凭据或已过期为 404。
