# VChat 0.3.6 beta 4

**iPhone · build 22 · iOS 17.0 及以上**

### 同步后可以直接翻看恢复点

修复了已有大容量恢复点时，双向同步结束后滑动列表可能导致的闪退。列表只读日期和同步前后的话题数。旧恢复点首次打开时建立索引，原备份保留；点「恢复此前状态」并确认后才加载选中的备份，恢复前的状态也会另存一份。

### 工具调用和回执更好读

原生 FC 调用 DailyNote 新建或修改日记时，会显示日记卡。群聊中同一位 Agent 并行调用多个工具，重开话题由另一位 Agent 接话时，各份回执仍按原调用 ID 配对。批量工具回执可以直接阅读表格、列表、链接和代码，返回的原始 HTML 按文本显示。

### 从旧消息分支，或只追问一句

在单聊或群聊的消息菜单选「从这里另开话题」，保留截至该条消息的历史，原话题不变。只想问一句时，长按助手正文选中文字，再选「单独追问」。

### 后台回复与图片

启用可选的 [VChatReplySync 插件](../../Companion/VChatReplySync/README.md)后，切后台或重开 App 可以继续接收原来那条回复。聊天里的 Markdown 和 HTML 图片也可以保存到系统相册。

**覆盖安装：** 从 [GitHub Releases](https://github.com/silk2onion/vcpchat-ios/releases) 选择对应版本的未签名 IPA，用 AltStore 和原 Apple ID 覆盖安装，不要先卸载旧版。
